# 0.21.0 自动召回配对验证

2026-11-18。基线使用提交 `4c0acd3` 的召回与存储代码，新版使用当前 `0.21.0` 工作树。两组读取同一临时记忆库，包含 4 篇合成业务笔记和 90 篇较新的干扰笔记。每个条件使用新会话，交替运行两组。每轮先走插件的 `agent/pre-step` 召回，再把生成的消息交给回答模型。两步都使用 DeepSeek Flash，关闭思考，选择器超时设为 12 秒。请求只包含合成材料。

新版的纠正场景中，旧命令既未进入选择提示，也未附加给回答模型。总 token 来自 API 返回值。召回耗时从触发钩子到返回主模型的消息，包括本地候选准备和选择请求。每场景每组各运行一次，结果用于验证这四条路径，样本不足以估计整体误召回率或延迟分布。

配对调用使用 [DeepSeek Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)。DSH 的 `cc-memory-eval` profile 指向另一份插件，现有 headless 评测的源码预检未通过。仓库另外执行了冻结清单校验与假模型编排验证。
